# 日本一のアイドル事務所を作ろう

アイドルグループを育成する、ブラウザーで遊べる育成シミュレーションです。

## はじめに

あなたは事務所オーナーです。新人を育成し、楽曲を発売し、ライブを催して、競合からファンを奪い業界1位を目指してください。

時間は毎週水曜日を起点として進みます。半年ごとに計画を策定するため、長期間遊んでも無理なく進められます。

**初期資金は1億円。** ただし毎月、メンバーとマネージャーの給与が口座から引き落とされます。売上とファン数を伸ばさないと経営は立ち行きません。

## 起動方法

`index.html` をブラウザーで開くだけで遊べます。ビルドや、追加ソフトのインストールは不要です。

タイトル画面にはセーブ枠が3つ用意されています。「続きから」で再開、「新規開始」で最初から、「削除」でデータを消せます。

## 画面の構成

| 画面 | 見えるもの |
| --- | --- |
| **グループ** | 選抜チームの総合力、センター、グループ推定ファン数、楽曲のレベルと売上 |
| **編成** | 常時表示のメンバー名一覧、選抜/アンダーの切り替え、選抜・センターの変更、14の能力値 |
| **事務所** | 水曜基準のカレンダー、週間スケジュール、マネージャー、設備投資、タイトル画面へ戻る |
| **資金** | 現在の資金（6桁以上は万円、9桁以上は億円で表示）、年間売上、ライブ動員、ファンクラブ、給与明細 |
| **順位** | 業界順位。他グループの売上・動員・公演回数・総合力との比較 |
| **記録** | 最近起きた出来事と計画のログ |

## 一週間の流れ

事務所画面で1つの行動を選ぶと、次の水曜日に進みます。

### 選べる行動

**ライブがない週**は「1週間のスケジュール」を組み立てます。**7日×午前/午後で14枠**が固定で、各枠に内容を選んでいきます。テレビ出演（歌番組など）やCD発売などのイベントがある週でも組み立てられます。

| 枠の内容 | 効果 |
| --- | --- |
| ダンスレッスン | 選抜全員のダンス（＋運動能力・体力）の経験値 |
| 歌唱レッスン | 選抜全員の歌唱力（＋体力）の経験値 |
| リテラシー講義 | 選抜全員の学力（＋トーク力）の経験値 |
| **筋力トレーニング** | 選抜全員の**運動能力**の経験値（消費やや大め） |
| **持久力トレーニング** | 選抜全員の**体力**の経験値 |
| **通し練習** | 選抜全員の**ダンス＋歌唱**の経験値。**1週間で2枠まで** |
| **連携** | 選抜全員の**連携力**の経験値。**グループ練習のみ** |
| 個別レッスン | 対象1名・能力1項目を集中育成（枠1つ） |
| 食事会 | **1回あたり100万円**。選抜の人気＋2・グループ危機回避力＋3・体力値＋10回復 |
| 休養 | レッスンも体力消費もしない枠。体力値が回復し、ケガのリスクが下がります |
| 1週間の休暇 | 下記 |

- **休養は「1日フル＋2枠」が基本**。1日の午前・午後を両方休養にすると「1日フル休養」として扱われ、残り2枠を別の休養に充てると1週間の体力バランスが取れます。休養日の行は緑色で強調されます。
- **1週間の休暇**はスケジュール上部のボタンで切り替えられます。**14枠すべてが休養**になり、全員が**体力値＋45**回復します。レッスンも食事会もケガも一切発生しませんが、1週間分の経験値は獲得できません。
- **枠の並びは自由**です。「ダンス×4＋歌唱×3＋リテラシー×3＋休養4」のような配分にできます。
- 食事会の経費が資金を超える場合は、週間スケジュールを確定できません（先に食事会の枠を減らす必要があります）。

### 追加トレーニングの制約

- **通し練習は1週間2枠まで**です。3枠目を選ぶと選択肢から「通し練習（1週2枠まで）」として無効化され、選べません（スケジュール下部に現在の枠数が表示されます）。
- **連携はグループ練習のみ**です。個別レッスンでは鍛えられず、**実際に参加できるメンバーが2名未満の週（休養日・ケガ者が多い場合）は未実施**になり、週次ログに「連携: 参加者が2名未満のため未実施」と出ます。

- **特別強化**：対象をチェックすると、グループレッスンの**段階倍率つき**（基礎10倍〜極20倍）の経験値を得られます。**マネージャーの4能力はすべてこの特別強化にだけ効きます**（強化倍率・強化人数・体力消費軽減・ケガ率低減）。追加の体力消費は1週間につき1回だけ加算されます。
- **休養日の打診**：体力値が30を下回るメンバーがいると、マネージャーから休養打診が表示されます。チェックしたメンバーはその週のレッスンに一切参加せず、体力値も大きく回復します。

### 事務作業はレッスンと同じ週に行う

事務作業（シングル販促／次のライブの広報／グッズの開発）は**週間スケジュールの一部**です。レッスンの枠を組んだまま事務作業を1つ選び、「このスケジュールで1週間進める」を押すと、**メンバーの練習と事務作業を同じ週にまとめて実行**します。

| 事務作業 | 効果 |
| --- | --- |
| シングル販促 | 発売予定のシングルに販促ポイント+1・楽曲経験値+3。該当が無ければ選抜メンバーの人気+1 |
| 次のライブの広報 | 次回ライブの集客効果が累計で上昇 |
| グッズの開発 | グッズを1種開発（在庫+1,000個 / 開発費50万円 / 上限5種） |

- **「何もしない」も選べます**（既定値）。事務作業をスキップしたい週はそのままレッスンだけ実施します。
- 選択中の事務作業は説明文が下に表示されます。グッズが上限5種に達している場合は選択できません。
- **1週間の休暇中も事務作業は実行されます**（メンバーは休養しますが、事務作業は所長の業務なので）。
- グッズの開発費が資金を超える場合は、その週を進められません。

ライブ（自分のライブ・出演決定済みのイベント・他グループの公演）がある週は「ライブ週」となり、週間スケジュールは組めません。テレビ出演やCD関連イベントなど、**ライブ以外のイベントがある週は通常どおりスケジュールを組めます**（その週の出来事はスケジュール画面の上部に表示されます）。

### テレビ出演は週枠に固定される

歌番組などのテレビ出演は、**放送日の午後枠**に「テレビ出演: 番組名」として枠埋めされます。**その直前の午前枠は「リハーサル」で固定**されるため、どちらの枠も変更できません。

- 固定枠は水色で表示され、プルダウンから選べません（週のグリッドの選択肢から除外されます）。
- リハーサル1回で**体力値−4**、出演1回で**体力値−3**が選抜全員に掛かります（レッスン経験値は得ません）。
- **テレビ出演がある週は1週間の休暇をとれません**（出演は取り消せないため）。
- 週をまたいで放送日を跨いでも、出演内容は自動的に処理されます（人気増加・楽曲経験値増加・出演料の入金）。

### そのほか起きること

- 毎週、危機対応・ファンクラブ・ランダム事件（設備強化の打診を含む）・設備整理の提案などの場面が現れ、選択肢を迫られます。
- **ライブ当日**は自動で時間が進み、売上と動員、ファン数の増加が起きます。
- **テレビ出演当日**の出演内容は自動で処理され、出演人気度と楽曲レベルが上がります（週を跨いで放送日をまたいでも処理されます）。
- 月が変わると計画画面が開き、半年分のリリースとライブを組み立てます。

## 能力の経験値システム

- 能力値を1上げるのに必要な経験値は **100 × 1.05^(現在のレベル−1)** です。
- レベルが高いほど必要な経験値が増え、レベル100が上限です。
- レッスン1回の基礎経験値は事務所「レッスン」設備とマネージャーの**統率力**で伸びます。
- 編成画面では各能力の経験値の進捗バーが表示されます。

## 体力値とケガ

- メンバーごとに**体力値（0〜100）**があり、レッスンやライブで消費されます。
- 毎週**回復力**と事務所「寮」の効果で自然回復します。休養日を設けると回復量は2.5倍です。
- 体力値が30を下回った状態で練習を続けると、**ケガまたは体調不良**が起き、1〜3週間レッスンに参加できません。
- ケガ中は回復がさらに1.5倍になります。マネージャーの**メンタルケア**があれば発生率が下がります。

### ライブによる体力消費

ライブ1日ごとに、選抜全員の体力値が**会場規模に応じて消費**されます。大きな球場やドームほど負担が大きい設計です。

| 会場規模 | 消費 |
| --- | --- |
| SS / S | 約29 / 26 |
| A / B | 約23 / 20 |
| C / D | 約16 / 14 |

- ライブは1月あたり最大3会場・計8公演までなので、**全部やると1月で100近く消費**されます。週間スケジュールのレッスン（消費51前後）と合わせると、計画的に休養を挟む必要があります。
- **前日もライブだった場合**は消費が1.15倍になります。

### ライブ疲労（回復力の一時的な鈍化）

ライブ、特に**複数日にまたがるライブ**では**ライブ疲労**がたまります。

- 疲労は0〜100で、**複数日にまたがるライブや連日公演では急にたまります**。
  - 単独のワンデイ公演：+18
  - 複数日にまたがるライブ：+26
  - 前日もライブだった場合：+24（両方なら+32）
- **疲労がたまると回復力が落ちます**（疲労100で回復力−50%）。次の週のレッスンで回復が遅れます。
- 疲労は**毎週20ずつ**自動で解けます（一時的なもの）。
- 編成画面のメンバー詳細で、現在の疲労値と回復力への影響をいつでも確認できます。

### ライブ週の自然回復

ライブがある週は「ライブ週」となり週間スケジュールを組めません。この週は**自然回復がライブの日に1回だけ適用**されるため、ライブがなければ体力は回復します。テレビ出演などのみがある週はスケジュール側で回復が適用されます。

## リリースとライブの計画

計画は**ゲーム開始直後と1月・7月**の年に2回。半年分のリリースとライブを一緒に決めます。

計画は「**6か月分のカレンダー**」と「**月ごとのブース**」の2画面で構成されています。まず日程を決め、続いて詳細を詰めます。

### 6か月分のカレンダー

事務所画面の「**半年計画カレンダーを開く（6か月分）**」（または計画画面内の「📅 カレンダーで日程を選ぶ」）から開きます。

- 半年分の**6ヶ月が並べて表示**され、日付ごとに **CD発売／ライブ／イベント／他グループの公演／放送** の印がつきます。
- 日付をタップして選択し、上のボタンで**まとめて設定**できます。
  | ボタン | 内容 |
  | --- | --- |
  | **CD発売に設定** | 選んだ日がその月の発売日に 됩니다（1か月に1つだけ。複数日を選んだ場合は各月の最初の日付を採用） |
  | **ライブに設定** | 選んだ日がその月のライブ公演日になります（会場は自動で割り当てられるので、詳細で変更できます） |
  | **イベントに設定** | 選んだ日がその月のCD関連イベントになります（1か月最大3件） |
  | **ライブ・イベントを解除** | 選んだ日のライブ公演日・イベントを消します（CD発売は月単位のため残ります） |
  | **範囲選択** | ONにすると、続けてタップした日までの日程をまとめて選べます |
- **今日より前の日付は選択できません**（薄く表示され、タップしても反応しません）。
- 各月の「**詳細**」を押すと、その月のブースに直接移動します。
- カレンダーで設定した内容は**月ごとのブースにそのまま反映**され、ブース⇄カレンダーを往復しても編集内容は失われません。

### 月ごとのブース（詳細設定）

カレンダーと同じ計画画面の下に、**月ごとのブース**が並んでいます。ここでは日程 말고内容を詰めます。

- **リリース**：シングル／アルバム／なし、**発売日**、楽曲名、CD特典
  - 発売日を空欄にすると、**従来どおり当月の最終水曜**に発売します。
  - 時間は毎週水曜で進むため、発売日・イベント日を水曜以外の日に置くと**その週の水曜に処理**されます。
- **ライブ**：1月あたり最大3会場・計8公演。会場・ライブ名・公演日・席種ごとのチケット価格・注釈席／ステージバック席の有無。
- **CD関連イベント**：1月あたり最大3件。特典ウェブ挨拶／リアル挨拶／ウェブサイン／リアルサインイベント／グッズ販売イベントから選べます。
  - 開催日に経費を払い、選抜メンバーの人気から完売率・売上が算出されます。グッズ販売イベントは現在のグッズ在庫を売ります。
  - イベント開催週も週間スケジュールは組めます（開催週のイベントとしてスケジュール画面の上部に表示されます）。

### リリース

- 楽曲名・ライブ名は自由に入力できます。空欄なら自動で名が付きます。
- シングルやアルバムには**特典**を付けられます。特典イベントでファンが増える仕組みです。
  - ウェブ挨拶（200万円）／リアル挨拶（500万円）
  - ウェブサイン（400万円）／リアルサイン（1,000万円）
- リリースの約**10週間前**に、選抜メンバーとセンターを決めます。
- 楽曲は週行動やテレビ出演でレベルが上がり、レベルが高いほど初動が良くなります。

### ライブ

- 1か月につき**最大3会場・計8公演**まで。1公演＝1日で、同じ会場の連続公演も可能です。
- 公演日は**日曜＞土曜＞金曜＞その他**の順に埋まりやすい。会場使用料は会場の規模と曜で変動し、同じ会場で多く公演するほど割安になります。
- **小会場は45日前まで、球場やドームは180日前まで**に予約が必要です。
- 計画画面には**他グループの公演予定**も表示されます。同日・同会場は予約できません。
- 席種別の価格を設定でき、注釈席・ステージバック席は設置の有無を選べます。

### テレビ出演

発売月の1か月前には **Song Station／CTV／Mコン** から出演打診が届きます。ランダムで有名アーティストとの対バンや大型フェスへの出演も発生します。出演ごとに受諾・辞退と披露曲を選びます。

放送日は固定されています。

| 番組 | 放送日 |
| --- | --- |
| **CTV** | 月曜日 |
| **Mコン** | 火曜日 |
| **Song Station** | 金曜日 |
| **日本CD大賞** | 12/30 |
| **赤白歌合戦** | 12/31（成績上位2枠なら出演） |

出演すると選抜メンバーの人気度が上がります。**赤白歌合戦**は成績の上位2枠に入れば大きな人気が得られます。

### 大型特番

年に6回の大型特番があり、放送日の約4週間前に出演打診が届きます。出演すると**定例番組の4〜8倍**の人気度が得られます。

| 特番 | 放送日 | 人気倍率 |
| --- | --- | --- |
| 卒業SP | 3/9 | ×4 |
| 新生活SP | 4/8 | ×4 |
| 夏Music Show | 8月第2土曜 | ×6 |
| ハロウィンSP | 10/31 | ×5 |
| クリスマスSP | 12/23 | ×5 |
| 年越しSP | 12/31〜1/1 | ×8 |

出演には**出演料**が伴い、楽曲レベルの上昇も大きくなります。

## 選抜とセンター

- **新曲発売の10週間前**に「選抜発表」が出て、選抜とセンターを自分で決めます。
- チェックしたメンバーが**選抜**になり、選抜の中から**センターを1名**選びます（最少3名）。
- 編成ページの「**選抜・センターを変更する**」から、いつでも手動で変更できます。
- 選抜はグループ成績・売上・ファン数・レッスン経験値のすべてに反映されるため、**誰を出演させるかは戦略的な判断**です。
- センターは**必ず選抜内**から選ぶ必要があります（選抜外のメンバーは選べません）。
- 前回の選抜とセンターは引き継がれた状態でモーダルが開きます。

### 選抜の確定（ロック）

- **発表で確定した選抜は、次作の発売10週間前まで変更できません。**
- 編成ページのボタンは「選抜確定済み（◯年◯月）」と表示され、押しても開きません。
- ただし**スキャンダル・危機対応が起きたとき**と**選抜メンバーが卒業したとき**は、編成の見直しが必要になるのでロックが解除されます。

## メンバーを育てる

- 編成ページ上部に**メンバー名一覧が常に表示**されます。タブの開閉やクリックなしで全員のフルネームが参照できます。
- 各チップには **フルネーム・年齢・体力値** が表示され、以下が色分けされます。
  - **選抜**はピンクの背景
  - **センター**は `C` マークとピンクの枠
  - **体力値が30未満**は数値が赤字、ケガ中の場合はチップ名に「ケガ／体調不良」を併記
- 一覧の並びは **選抜 → センター → 名前順** なので、中心メンバーが常に先頭に来ます。
- 読み（ふりがな）は詳細カードで表示されます。ひらがなの名前の場合はそのまま表示されます。

- 開始時は30人が在籍しています。**選抜**のメンバーと**アンダー**のメンバーで育成方針が分かれます。
- メンバーごとに年齢・身長・誕生日があり、14の能力値と総評を確認できます。身長は加入時に決まったあと変わりません。
- 能力値の並びは 人気／スタイル／ファッション／歌唱力／ダンス／**体力／回復力**／トーク力／SNS運用／バラエティ耐性／学力／運動能力／危機回避力／**連携力** です。
  - **連携力**はグループでの表現をよりよくするための能力なので、**連携（集团練習のみ）**でしか上げられません。個別レッスンでは指定できません。
- センターはリリースの約10週間前に決まります。
- **2月29日生まれ**のメンバーも在籍します（平年では3月1日に年齢が増えます）。
- 誕生日が同じメンバーが複数いることもあります。
- 一定の年齢を超えると**卒業の相談**が持ち上がります。
  - 慰留を交渉する
  - 卒業を承認してセレモニーを開く
  - 卒業コンサートを追加する
  - 卒業グッズを作る

## マネージャー制度

開始時から**1人**のマネージャーが在籍しています。事務所画面でレベルアップ・採用・解雇ができます（最大5人）。

- 4つの能力はすべて**Lv.1〜Lv.10**。**レベルアップのみ**存在し、ダウングレードはできません。
- レベルアップ費用は `12万円 × 1.5^(現在レベル−1)` で上がり続けます。採用費は200万円です。

| 能力 | 効果（すべて特別強化に適用） |
| --- | --- |
| **統率力** | 特別強化の倍率を上げる |
| **スケジュール管理力** | 同時に特別強化できる人数を増やす |
| **メンタルケア** | 特別強化時の体力消費を抑える |
| **リスクマネジメント** | 特別強化中のケガ・体調不良を減らす |

効果の段階は**在籍マネージャーの項目別合計レベル**で決まります。同じ合計なら「1人のLv10」と「5人のLv2」は同じ効果です。

### 効果段階（項目別の合計レベル）

| 合計レベル | 段階 | 倍率 |
| --- | --- | --- |
| 0〜2 | **E** | ×1.00 |
| 3〜5 | **D** | ×1.05 |
| 6〜9 | **C** | ×1.10 |
| 10〜15 | **B** | ×1.20 |
| 16〜24 | **A** | ×1.35 |
| 25〜37 | **S** | ×1.50 |
| 38〜49 | **SS** | ×1.70 |
| 50 | **極** | ×2.00 |


- 強化人数の制限は**スケジュール管理力**のみ（E〜C=1名、B〜SS=2名、極=3名）。
- 体力消費軽減とケガ率低減の上限はそれぞれ75%です。
- 合計の理論上限は **5名 × Lv10 = 50**（＝**極**）です。

### マネージャー市場

**マネージャー市場は常に開いており**、事務所画面の「マネージャー市場」に25〜35歳の女性の求人が **5名**並んでいます。

- 各カードで**名前・年齢・4項目のレベル・月給**を確認してから採用できます（採用費200万円）。
- 求人は**採用・退職で空いた枠だけ補充**されるので、検討中の他の候補はそのまま残ります。
- **40〜45歳のタイミングで任意退職**します。ただし**退職の時期は事前に分かりません**。カードは「在籍：安定」などの曖昧な表示のみです。
- **解雇する時は4か月分の給料**を支払う必要があります。支払えない場合は解雇できません。

## 年収・給与

毎月末に、メンバーとマネージャーの給与が**月割り**で一括引き落とされます。「資金」画面で内訳を確認できます。

### メンバー
- 人気と売上を伸ばすとファン数が増えるため、**年収もそのまま上がります**。
- グループ全体のファン増減分は前年との差で計算され、1年目（前年データなし）は0として扱われます。

### マネージャー

- 全能力Lv.1なら年収432万円、Lv.10が4つ揃えば1,020万円です。

## 事務所を投資する

事務所ではレッスン・寮・データ分析・SNS教育・ライブ演出・グッズの**6設備**を資金で投資できます。

- レベルは最大**Lv.10**。Lv.1の週維持費は0円で、Lv.2以降はレベルが上がるほど開発費も維持費も増えます。
- Lv.2以降は**ダウングレード（売却）**も可能で、売却額は資金に戻ります。
- 資金が週維持費を下回る週には縮小提案が出されます。
- 能力差、SNSスキャンダル、グッズ販売率、競合の影響力に応じて、設備の強化提案が発生することがあります。

## 競合との競争

- 他グループも**毎月ライブを開催**します。影響力が高いほど開催頻度が高く、公演回数も多くなります（1〜4公演）。
- 連日公演を行うこともあり、その場合は計画画面に「連日」と表示されます。カレンダーにも他公演日の印がつきます。
- 順位画面の**総合力**は、自グループが選抜チームの平均評価、他グループが売上に応じて増減する影響力です。自グループの売上が伸びると、順位も上がります。
- 時間が経つと**新しい競合グループが加わります**。名前は自動でつけられ、既存のグループと重複することはありません。

## 危機とランダムイベント

情報漏洩やSNSスキャンダルが起きると、謝罪・謹慎・罰金・懲戒処分の4択から対応方針を選びます。対応によって資金・危機回避力・人気への影響が変わります。

また、ランダムイベントも突然発生します。発生する週はあらかじめ通知されず、その週のダイアログが開きます。いつ起きるか分からないので、資金や人気の変化は日常的に確認しておきましょう。

- **設備強化の打診**もランダムイベントの一部です。他グループとの能力差やグッズの完売率から強化対象の設備が挙がり、**強化を引き受ける／今回は見送る**の2択で応じます。受け入れると開発費を払い、対象設備が1レベル上がります（資金不足のときはその選択肢を選べません）。すべての設備が最大レベルなら打診は来ません。
- ランダムイベントとは別に、**資金難のときは設備整理（ダウングレード）の提案**が毎週発生することがあります。Lv.2以上の設備を1段階下げて売却額を回収するか、週間維持費を減らして見送るかを選びます。

## ファン数と売上

- メンバーの**人気**が高いほど、そのメンバーの推定ファン数も増えます。歌唱力やダンス、トーク力が高いほどファンも増えます。
- グループ推定ファン数はメンバーのファン数をまとめたものです。ファン同士が重複するため、実際の合計より低い値になります。
- **グループ危機回避力**とメンバーの**SNS運用**が高いほど、情報漏洩やスキャンダルの起きにくくなります。データ分析とSNS教育の設備も効果を高めます。
- グッズやCD特典イベントの販売数・完売率は、参加メンバーの人気から算出されます。事務所画面で在庫・累計販売数・直近完売率を確認できます。
- シングルやアルバムの売上、ライブの収支は「資金」画面で、曲別の売上は「グループ」画面で確認できます。

## 年をまたぐ変化

- **年末**には日本CD大賞（12/30）と赤白歌合戦（12/31）が開催され、成績に応じて賞や資金ボーナスを受け取ります。
- **2年目**の幕開けにファンクラブ（会費）の設立打診が届きます。以降は年に1回、会費と特典を見直します。会費収入は毎月入金されます。
- 1月になるとグループファン数の1月頭値が記録され、前年との差が次の年のメンバー年収に加算されます。
- メンバーは年末ごとに在籍年数が加算されます。

## ドラフト会議

約2年半ごとにドラフト会議が開かれます。毎回、全国から集まった候補生の中から10〜15名を選んで獲得できます。

- 前回のドラフト時点のグループ総合力で順位づけされ、**逆ウェーバー方式**（下位のグループから先に指名）で進みます。
- 獲得人数は**10〜15名**から自由に選べます。
- 各巡で候補生5名から1名を指名します。
- **1位指名のみ**、上位のグループも注目しているため候補者が重複することがあります。重複時は抽選になり、外れると外れ1位で別の有望株を獲得します。

候補生カードの見かた:

```
高田 奈月　18歳 / 158.3cm（2008年9月4日生）
総評 54
人気 48 / スタイル 72 / ファッション 52 / 歌唱力 47
```

- カードには年齢・身長・生年月日・総評と、4つの能力値が表示されます。
- 残り9つの能力値は、指名したあと「編成」画面で確認できます。
- 候補生は14〜20歳のみ。氏名・身長・誕生日・能力値は会議ごとに決まります。

## セーブデータ

進行内容は選択中の枠へ自動保存されます。枠は3つあり、それぞれ独立しています。タイトル画面からいつでも再開・上書き・削除できます。

## 遊ぶときのヒント

- ライブがない週に週間スケジュールを組みましょう。**休養日**を設けないと、ケガと体調不良が発生します。歌番組などのテレビ出演がある週もスケジュールは組めます（放送日の午後は出演、午前はリハーサルで固定）。
- **特別強化**は毎週使えます。伸びたい能力を決め打ちにして集中育成するのが効率的です。
- 大型特番は定例番組より多くの経験値が得られます。放送日前の打診は逃さないこと。
- マネージャーの**スケジュール管理力**を上げておくと、1週間に組めるレッスン枠が増えて月あたりの経験値も増えます。
- 人数は多ければよいわけではなく、選抜で活かせる能力が高いメンバーを集めるのがコツです。
- 年齢が高いメンバーは卒業が近づきます。
- 有力な競合は公演が頻繁で、よい日程も埋まっていきます。
- 資金が週維持費を下回ると縮小提案が出ます。設備投資は無理のない計画で。
