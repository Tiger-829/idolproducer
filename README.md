# 日本一のアイドル事務所を作ろう

アイドルグループの運営を体験する、ブラウザー向けの育成シミュレーションゲームです。メンバーや楽曲の状態を見ながら、発売計画やライブを決め、グループを成長させます。

## 起動方法

`index.html` をブラウザーで開くとタイトル画面が表示されます。ビルドや追加パッケージは不要です。タイトル画面では3つのセーブ枠から、続きからの再開、新規開始、データ削除を選べます。旧形式のセーブデータがある場合は枠1へ移行します。

## 画面

- **グループ**: 選抜チームの総合力、センター、グループ推定ファン数、楽曲のレベルと売上を確認します。
- **編成**: 選抜メンバーとアンダーを切り替えます。メンバーを開くと、年齢・総評・個人推定ファン数と12種類の能力値を確認できます。
- **事務所**: 水曜基準のカレンダー、週行動、半年計画、設備投資、タイトル画面への移動を行います。
- **資金**: 現在の資金（5桁までは円、6桁以上は万円、9桁以上は億円で表示）と年間売上・ライブ動員・ファンクラブを確認します。
- **順位**: 業界順位を確認し、他グループの売上・動員・公演回数・総合力を比較します。
- **記録**: 直近に発生したイベントや計画のログを確認します。

## ゲームの進め方

1. 操作日は水曜日が基本です。週行動パネルで行動を選ぶと次の水曜日へ進みます。月間カレンダーには現在日とライブ予定が表示され、日付が変わるとページがめくれます。イベント日やライブ日ではイベント進行のみを行います。
2. レッスン・育成は対象メンバーの能力を上げます。シングル販促は次回シングルの売上、ライブ広報は次回ライブの動員に効果があります。グッズ開発は1商品あたり50万円かかり、ライブで追加売上を得られます。
3. ゲーム開始直後と1月・7月に半年分のリリース・ライブ計画を決めます。楽曲名・ライブ名は自由に入力でき、空欄の楽曲名は自動設定されます。シングルやアルバムの発売に特典を付ける場合は、特典ウェブ挨拶（200万円）、リアル挨拶（500万円）、ウェブサイン（400万円）、リアルサインイベント（1,000万円）から選びます。
4. 1か月につき最大3会場・計8公演まで開催できます。同じ会場で複数の公演日を選べ、1公演=1日です。公演日は日曜＞土曜＞金曜＞その他の順に会場が埋まりやすくなります。会場使用料は会場ランク（収容人数×ランク単価）を基本料金とし、公演日の曜に応じた割り引きを適用してから日数分を加算します。曜割り引きは、日曜を含む場合は元値、日曜を含まず土曜を含む場合は0.95倍、金曜が最終公演日の場合は0.8倍、それ以外は0.75倍です。`利用料 = (基本料金×曜割引) × (1 + 0.2×(公演数-1))` で計算します。（例：大宮アリーナの基本8,100万円で1公演なら日曜8,100万円／土曜7,695万円／金曜6,480万円／水曜6,075万円、5公演で土曜を含むなら1億3,851万円）。小会場は開催日の45日以上前、球場・ドームは野球日程との調整のため180日以上前に予約が必要です。計画画面には他グループの公演予定も表示され、同日・同会場は予約できません。席種別の価格も設定でき、注釈席・ステージバック席は設置可否を選べます。
5. リリースの約12週間前に、選抜メンバーとセンターを決めます。
6. 発売月の1か月前には Song Station、CTV、Mコンから出演打診があります。夏（7月）と冬（12月）には大型音楽特番の打診もあります。ランダムで有名アーティストとの対バンや大型フェスの出演打診も発生します。出演ごとに受諾・辞退と披露曲を選びます。
7. 楽曲は週ごとの活動で経験値を得て成長し、テレビ出演でも経験値を得ます。レベルは発売時の売上にも影響します。
8. 2年目の幕開けにファンクラブ（会費）の設立打診があり、以降は1年ごとに会費と特典を見直します。会費収入は毎月入金されます。
9. 順位画面では他グループとの競争成績を確認できます。総合力は自グループが選抜チームの平均評価、他グループが売上に応じて増減する影響力です。売上が伸びると順位も上がります。
10. 他グループも毎月ライブを開催します。影響力が高いほど開催頻度が高く、公演回数も多くなります（1〜4公演）。連日公演を行うこともあり、その場合は計画画面に「連日」表記で表示されます。カレンダーでは他グループの公演日のすべてに印がつきます。
11. 事務所ではレッスン、寮、データ分析、SNS教育、ライブ演出、グッズの6設備を資金で開発できます。Lv.1の週維持費は0円で、Lv.2以降はレベルに応じて開発費と維持費が増えます（最大Lv.10）。Lv.2以降はダウングレード（売却）も可能で、売却額は資金に戻ります。資金が週維持費を下回る週には縮小提案が出されます。能力差、SNSスキャンダル、グッズ販売率、競合の影響力などに応じ、設備強化イベントが発生することがあります。

## 危機とランダムイベント

情報漏洩やSNSスキャンダルが起きると、謝罪・謹慎・罰金・懲戒処分の4択から対応方針を選びます。選択肢によって資金・危機回避力・人気への影響が異なります。

また、現実のアイドル業界によくある事象（SNSバズ、雑誌取材、握手会の長蛇行列、配信者コラボ、ラジオ出演、噂の拡散、慈善イベント）がランダムで発生します。それぞれに選択肢があり、人気度や資金の増減に影響します。

## ファン数と売上

個人推定ファン数は、メンバーの能力値から次のように算出します。

`人気 × 28 + (歌唱力 + ダンス) × 9 + トーク力 × 5`

ゲーム開始時のグループ合計はおよそ5万fanになります。

グループ推定ファン数は所属メンバーの個人推定ファン数を合計し、ファンの重複を考慮して65%に調整した値です。この数値はCDの需要とライブ動員の計算に使われます。

メンバーにはSNS運用能力があり、グループ危機回避力と合わせて情報漏洩やSNSスキャンダルの発生率に影響します。データ分析とSNS教育の設備も危機回避に役立ちます。これらの危機イベントは水曜の週進行時に抽選されます。

グッズやCD特典イベントの販売数・完売率は、参加メンバーごとの人気をもとに計算します。グッズ販売では開発した在庫がライブで販売され、在庫数・累計販売数・直近完売率を事務所画面で確認できます。選抜発表時には、各メンバーの直近グッズ平均と特典イベント平均の完売率が参考情報として表示されます。完売率が低い場合はデータ分析設備の強化提案が発生しやすくなります。

シングル・アルバムの売上やライブ収支は「資金」画面で確認できます。曲別の発売売上は「グループ」画面に記録されます。現在の記録方式より前に発売された楽曲は、曲別売上を表示できない場合があります。

## 長期イベント

- 年末に年間アワードが開催され、成績によって賞や資金ボーナスが発生します。
- メンバーは重複しない誕生日（月日、1〜28日）を持ち、誕生日が属するゲーム内の週に加齢します。年末には在籍年数が加算されます。一定の年齢以降は卒業の相談が発生することがあります。慰留、常設ライブ内のセレモニー、追加または単独の卒業コンサート、卒業グッズ制作から選べます。
- 会場を使う卒業イベントでは収容人数に応じた利用料がかかります。卒業グッズは制作費と売上が資金に反映されます。
- 120週ごとにドラフト会議があり、新メンバーが加入します。前回ドラフト時点のグループ総合値で順位付けし、**逆ウェーバー方式**（下位のグループから順に指名）で進みます。
  - 獲得人数は**10〜15名**から自由に選べます。
  - 各巡で候補生5名から1名を指名します。
  - **1位指名のみ**、上位 他チームも注目しているため重複の可能性があります。重複時は抽選になり、外れると外れ1位で別有望株を獲得します。

## セーブデータ

進行内容は選択中の枠へ自動保存されます。枠ごとに独立しており、タイトル画面からいつでも再開・上書きして新規開始・削除できます。
